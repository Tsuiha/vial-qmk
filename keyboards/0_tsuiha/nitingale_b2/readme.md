# NitingaleB2

30keys keyboard with curved layout

* Keyboard Maintainer: Tsuiha
* Hardware Supported: NitingaleB2 PCB
* Hardware Availability: [Design Data](https://github.com/Tsuiha/)

2version shapes are available.
1. Left-hand
2. Right-hand

Make example for this keyboard (after setting up your build environment):

	make 0_tsuiha/nitingale_b2/left:vial
